# Code of conduct

## The short version

Treat people here the way you would treat a colleague on a tough release day. Direct about the work, decent about the person.

## What that means in practice

Critique goes to code, rules, and reports. It never goes to the person who wrote them. Questions at any level are welcome. Claims data work has a long tail of odd formats and edge cases, and nobody has seen all of them.

Harassment, personal attacks, and slurs are not welcome in issues, pull requests, or any project space. Sharing private information about another person is not welcome either. Sample data in this project is synthetic and must stay that way, so never post real claim lines anywhere in the project.

## Enforcement

The project maintainer reads reports sent through GitHub and acts on them. Responses scale with the behavior, from a quiet note to removing comments to blocking an account from the project.

## Scope

This covers every space tied to this repository, including issues, pull requests, discussions, and commit threads.
